# Python Data Analysis & Recommendation System

## Project Story

Congratulations! You have been selected as a **Python Data Analyst Intern** at a rapidly growing technology company. As part of your onboarding, your mentor assigns you a real-world challenge to evaluate your problem-solving and programming skills.

The company has accumulated a large collection of structured user data stored in JSON files. Unfortunately, the data is incomplete, inconsistent, and difficult to analyze. Before any meaningful insights can be extracted, the dataset must first be cleaned and organized.

Your first responsibility is to build a Python application capable of loading the dataset, validating records, removing duplicate and inconsistent entries, handling missing values, and transforming the data into a standardized format—all using only Python's built-in libraries.

Once the data has been cleaned, the next challenge is to discover meaningful relationships within the dataset. You are asked to design an intelligent recommendation engine that analyzes existing relationships between entities and suggests new connections based on shared associations using graph-based algorithms.

Impressed by your solution, your mentor presents one final challenge. The company wants to improve user engagement by recommending relevant items based on similar interests and historical preferences. You develop a similarity-based recommendation system that compares common interests, calculates recommendation scores, ranks potential suggestions, and generates personalized recommendations.

The entire project is implemented using core Python without external libraries such as Pandas or NumPy, demonstrating strong foundations in data structures, algorithms, data preprocessing, JSON processing, and recommendation system design.
